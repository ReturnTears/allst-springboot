## allst-springboot-dm：设计模式实录模块（从空脚手架建成）

- 定位：记录 Spring Boot 业务项目中 GoF 23 种设计模式 + Spring 机制的使用场景，回答「什么场景用哪个模式 / 不用会怎样 / 主要解决什么问题」。
- 技术选型：沿用父工程 Spring Boot 2.6.5、Java 11（`<release>11</release>`，本机 JDK 17 可编译）；显式声明 maven-surefire-plugin 2.22.2（父 pom 不是 starter-parent，默认 surefire 不支持 JUnit 5）。依赖含 web/validation/aop/data-jpa/data-redis/test、mysql-connector-java(runtime)、h2(test)、lombok 1.18.30。
- 存储约定：运行时 MySQL 8，`root` / 空密码，库 `allst_dm`（`createDatabaseIfNotExist=true`），JPA `ddl-auto: update`，表 `dm_order`；Redis 通过 `dm.redis.enabled` 开关切换 `KeyValueStore` 的内存/Redis 实现，默认关闭；测试用 `@ActiveProfiles("test")` + H2 内存库，不依赖外部服务。
- 代码结构：`common`(统一响应/异常)、`domain`(订单实体与仓储)、`support`(KV 抽象)、`creational`/`structural`/`behavioral`(按模式分包)、`showcase`(下单外观 PlaceOrderFacade、PatternCatalog 速查表、DemoRunner、DmShowcaseController)。一条下单主线把 23 种模式串起来，接口 `/api/dm/*`，端口 8367。
- 文档：`README.md` + `docs/README.md` + 10 篇分章文档（目标与读法、场景速查表、创建型/结构型/行为型、Spring 里的模式、MySQL/Redis、反模式、运行接口、开源参考）。开源项目引用按 ✅确认 / △推断 / ○通用场景 三档标注，不把推断写成源码事实；已核实 Sentinel ProcessorSlotChain 责任链、MyBatis CachingExecutor 装饰器与 MapperProxy 代理、Dubbo SPI、mall 电商结构。
- 验收：`mvn -o -pl allst-springboot-dm test` → 33 tests, 0 failures/errors, BUILD SUCCESS。曾修复两处：访问者示例接口方法名与 Lombok getter 不一致；装饰器测试受其它用例预热缓存影响（加 `PriceQuoteService.evict()` 隔离）。
- 约定沿用 state-machine 模块风格：README + docs 分章 + 可运行代码 + 不依赖外部服务的测试；`application-test.yml` 放在 src/main/resources。
