# 2026-11-19 工作日志

## allst-springboot-dm：新增「元数据驱动的多方言 DDL 生成」实战

用户需求：元数据表存表/字段/方言信息，按方言生成建表 DDL 并导出 SQL 文件；方言无清单（含 Impala 等 OLAP、偏门库），类型体系按方言自治，结果导出文件。

### 架构决策
- 本质识别为「两条变化轴（方言 × DDL 元素）+ 一条稳定轴（生成流程）」。
- 关键升级：方言差异不是「类型名不同」而是「片段有无」，故引入**能力模型 Capability**（PRIMARY_KEY/AUTO_INCREMENT/INLINE_*_COMMENT/POST_DDL_COMMENT/PARTITION/PARTITION_COLUMNS_SEPARATE/TABLE_OPTIONS/IF_NOT_EXISTS），替代 if-else。
- 模式组合：策略(DdlDialect 10 实现) + 能力模型 + 模板方法(AbstractDdlDialect.generate final 骨架) + 建造者(TableMeta/ColumnMeta build 校验) + 外观(DdlGenerator) + 工厂/注册(DialectRouter，Spring 注入 List 建 Map，未注册走 GENERIC 兜底)。
- Stream 发力：groupingBy(方言) / sorted(ordinal) / filter(空片段) / joining；刻意用顺序流（parallelStream 开销更大且 StringBuilder 非线程安全）。
- 类型体系自治：各方言 registerType 注册逻辑类型→物理类型映射，不认识的类型抛 BizException，不猜。

### 落地文件（包 com.allst.springboot.ddl）
- meta/：LogicalTypes、ColumnMeta、TableMeta、TableMetaRepository、MetadataSeeder（5 张多方言示例表）。
- dialect/：Capability、DdlDialect、DdlOutput、AbstractDdlDialect、DialectRouter + 10 方言（MySQL/PostgreSQL/Oracle/SQLServer/SQLite/Impala/Hive/ClickHouse/Doris/Generic）；AbstractHadoopDialect 抽 Impala/Hive 共性。
- generation/：DdlGenerator、DdlExportService（按方言分文件、UTF-8、路径防穿越）、DdlPlan/DialectScript/TableDdl/DdlRequest。
- api/：DdlController（/dialects、/generate、/export、/download、/files、/seed）。
- 配置：application.yml/test.yml 增加 dm.ddl.output-dir。
- 文档：docs/11-ddl-generation.md + 更新 README/docs 索引。

### 踩坑与修复
1. Impala/Hive 的 STRING 误用 withLength 生成 string(64)——Impala/Hive 的 STRING 是变长不写长度，改为固定 "string"。
2. 测试断言导出内容含 "CREATE TABLE"，但 Impala 输出 "CREATE EXTERNAL TABLE"，放宽为 "CREATE"。
3. 路径穿越测试用 ../ 被 Spring Web 层规范化成 404，断言接受 400/404。
4. 模板基类 renderColumn 初版留了占位符，已补全实现。
5. JPA：TableMeta.columns 改 EAGER 防离线生成 LazyInitializationException；ColumnMeta.table 加 @JsonIgnore 防反序列化递归。
