# 13 运行说明

## 数据库

MySQL 8，本机 `127.0.0.1:3306`，用户 `root`，密码为空。

在模块目录执行：

```bash
mysql -uroot --default-character-set=utf8mb4 --protocol=tcp --host=127.0.0.1 < src/main/resources/sql/bootstrap.sql
```

脚本会创建 `demo` 库和表，并用 `INSERT IGNORE` 写入示例数据，可以重复执行。它不会清空已有业务数据。

示例里有 7 本书、7 位作者、3 个分类、4 位读者、5 笔订阅。`go` 没有分类。科幻分类下没有书，用来试“空分类可以删除”。陈予安是停用读者，用来试“停用后不能新建订阅”。

## 后端

```bash
mvn spring-boot:run
```

端口 `8088`。

- GraphQL：<http://127.0.0.1:8088/graphql>
- GraphiQL：<http://127.0.0.1:8088/graphiql>
- 原来的 REST：<http://127.0.0.1:8088/book/getAll>

数据源密码在 `application.properties` 里是空的。CORS 允许任意来源，只为本地页面调试。

## 前端

```bash
cd frontend
npm install
npm run dev
```

页面在 <http://127.0.0.1:5173>。

## 建议点一遍的路径

1. 总览能看到书目 7、在订 2，以及最近一笔订阅。
2. 书目里改一本没有订阅的书，再新建一本然后删除。删除 `java` 应失败，因为它还有订阅。
3. 作者页改一个姓或名。
4. 新建分类，再把一本书归进去。删除“计算机”应失败。
5. 登记一位读者，再给这位读者订一本还没有在订的书。
6. 对停用读者新建订阅，应看到冲突说明。
7. 退订一笔，订阅页的实时说明应出现变动。

原来 README 里的 GraphiQL 查询仍然可以原样执行。
