# 08 分页、过滤、排序

列表不一次返回全表。读者和订阅使用同一套页码对象：

```graphql
input PageQuery {
    page: Int
    size: Int
    sortBy: String
    direction: SortDirection
}
```

约定：

- `page` 从 1 开始。不传时是第 1 页。
- `size` 不传时是 10，最大 50。
- `direction` 不传时是降序。
- `sortBy` 只接受白名单里的字段名。读者允许 `id`、`username`、`email`、`createdAt`、`status`。订阅允许 `id`、`createdAt`、`startDate`、`endDate`、`price`、`status`、`plan`。不在名单里的字段会被忽略，退回默认排序，避免把客户端字符串拼进排序。

返回结构：

```graphql
type MembershipPage {
    items: [Membership!]!
    pageInfo: PageInfo!
}
```

`PageInfo` 包含 `page`、`size`、`total`、`totalPages`。

过滤也是 input：

```graphql
query ($filter: MembershipFilter, $page: PageQuery) {
  memberships(filter: $filter, page: $page) {
    items { id status plan }
    pageInfo { page total totalPages }
  }
}
```

订阅的 `keyword` 同时匹配备注和书名。书名条件用子查询，不把 `Book` 做成 `Membership` 的懒加载关联。读者的 `keyword` 匹配姓名和邮箱。`LIKE` 会转义 `%` 和 `_`。

实现在 `ReaderService`、`MembershipService` 和 `PageRequests`，底层是 Spring Data 的 `Specification` 与 `Pageable`。
