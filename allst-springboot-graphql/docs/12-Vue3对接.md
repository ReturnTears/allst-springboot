# 12 Vue3 对接

前端在 `frontend/`，不放进 Spring 的静态目录。开发时 Vite 把 `/graphql` 和 `/subscriptions` 代理到 `127.0.0.1:8088`，浏览器只跟 `5173` 说话。

## HTTP

`src/api/graphql.js` 的 `gql(query, variables)` 发送 POST。响应里有 `errors` 时抛出第一条的 `message`，并带上 `extensions.code`。页面用这个消息显示横幅，不自己拼一套错误码文案。

各页面只请求自己要画的字段：

| 页面 | 主要操作 |
| --- | --- |
| 今天的流通 | `deskStats`、最近一笔 `memberships` |
| 书目 | `searchBooks`、`newBook`、`updateBook`、`deleteBook`、分类的指定和清除 |
| 作者 | `allAuthor`、`updateAuthorById` |
| 分类 | `categories` 及增删改 |
| 读者 | `readers` 分页筛选、增删改、`readerMemberships` |
| 订阅 | `memberships` 分页筛选、`planQuotes`、增改退删 |

书目页的新增仍调用原来的 `newBook`，用来说明旧接口可以和新页面放在一起。

## 实时

订阅页挂上之后连接 WebSocket。收到 `membershipChanged` 就写一句谁的哪本书有变动，并重新查询当前页。离开页面时关闭连接。

## 运行

```bash
cd frontend
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。

如果页面和接口不在同一台开发服务器上，可以设置：

- `VITE_GRAPHQL_HTTP`：GraphQL HTTP 地址
- `VITE_GRAPHQL_WS`：WebSocket 地址
