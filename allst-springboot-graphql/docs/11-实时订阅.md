# 11 实时订阅

这里的 Subscription 是 GraphQL 的推送操作，不是业务表里的那笔图书订阅。

```graphql
type Subscription {
    membershipChanged: Membership!
}
```

`MembershipSubscriptionResolver` 返回 `Publisher<Membership>`。事件来自 `MembershipEventBus`，内部是 Reactor 的多播 Sink。

创建、修改、退订、删除提交成功之后才发布。`MembershipService` 在事务 `afterCommit` 里调用事件总线，避免别的请求读到还没提交的数据。删除时推送的是删除前的那条记录，页面收到后重新拉列表即可。

已经是退订状态时再点退订，不会重复推送。

WebSocket 地址是 `ws://127.0.0.1:8088/subscriptions`。端点由 `spring-boot-starter-websocket` 注册，配置前缀是 `graphql.servlet.subscriptions.websocket`，默认路径就是 `/subscriptions`。子协议是 Kickstart 使用的 `graphql-ws`（subscriptions-transport-ws）：

1. 连接后发送 `connection_init`
2. 收到 `connection_ack`
3. 发送 `start`，payload 里是 `subscription { membershipChanged { ... } }`
4. 服务端用 `data` 消息推送

没有监听者时，发布结果会被记下调试日志并丢掉，不影响保存。

这个演示没有做登录。生产环境应限制谁可以订阅，并收紧 CORS。当前 CORS 为了本地 Vue 开成了 `*`，写在 `application.properties`。
