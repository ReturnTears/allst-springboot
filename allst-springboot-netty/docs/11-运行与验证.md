# 运行与验证

## 启动

在项目根目录：

```text
.\mvnw.cmd spring-boot:run
```

日志里应出现类似下面的行，线程名用方括号标出：

```text
[main] c.a.n.tcp.NettyTcpServerLifecycle - 仓储 TCP 服务已监听 /0.0.0.0:9000
[main] c.a.n.w.NettyWebSocketServerLifecycle - 仓管看板 WebSocket 已监听 /0.0.0.0:9001 路径 /ws/dashboard
[main] o.s.b.w.e.netty.NettyWebServer - Netty started on port 8080 (http)
[device-client-*] c.a.n.client.WarehouseDeviceClient - 设备 WH-SCANNER-01 已连接 127.0.0.1:9000 并发送 LOGIN
[warehouse-biz-*] c.a.netty.tcp.WarehouseServerHandler - 设备登录 deviceId=WH-SCANNER-01
```

然后打开 <http://localhost:8080>。顶部应变成「看板已接上 9001」。几秒内巷道里出现三台 `WH-SCANNER-*`，现场流水开始出现扫码。

底部「下发动作」选一台在线枪和库位，提交后流水里先出现「下发」，随后出现「回执」。服务端日志同时有「指令已回执」。

「记一笔扫码」用底部的条码和库位，不走随机生成。

## HTTP 抽查

设备在线后再执行。9000 上的枪不接受 HTTP。

```text
curl http://localhost:8080/api/devices
curl http://localhost:8080/api/events?limit=5
curl -X POST http://localhost:8080/api/devices/WH-SCANNER-01/commands ^
  -H "Content-Type: application/json" ^
  -d "{\"action\":\"MOVE\",\"params\":{\"aisle\":\"A-03\"}}"
```

下发的响应是 202，里面的 `requestId` 再拿去查：

```text
curl http://localhost:8080/api/commands/这里换成requestId
```

状态应从 `SENT` 变成 `ACKED`。对一个不存在的设备下发，响应是 404，`code` 为 `DEVICE_OFFLINE`。

SSE：

```text
curl -N http://localhost:8080/api/events/stream
```

`-N` 关掉缓冲后，能看到后续扫码以 `event:SCAN` 推过来。后连上的订阅者还会先收到最近的一段回放。

## 测试

```text
.\mvnw.cmd test
```

| 测试 | 覆盖 |
| --- | --- |
| `WarehouseCodecTest` | 帧头布局、两帧顺序、半包拼接、错误魔数 |
| `DeviceSessionRegistryTest` | 同一设备号二次登录会关掉旧连接；断开旧连接不会误删新会话 |
| `WarehouseGatewayTest` | 随机端口上的登录、扫码、202 下发、ACK、WebSocket 快照和增量 |

集成测试关闭模拟器，避免随机扫码混进断言。它使用的设备号是 `IT-SCANNER-01`。

## 只开其中一块

```yaml
netty:
  server:
    enabled: false
  websocket:
    enabled: false
  client:
    simulator-enabled: false
```

HTTP 仍然起来。`/api/meta` 里被关掉的端口是 `-1`，模拟扫码接口返回 409。

模拟器要连上本进程时，`netty.client.port` 必须和 `netty.server.port` 一致。启动日志会把「实际监听端口」和「模拟器拨号端口」都打出来，两边不一致时可以直接看出来。

## 端口被占用

默认占用 8080、9000、9001。改 `application.yml` 里的 `server.port`、`netty.server.port`、`netty.websocket.port`、`netty.client.port`。看板会读 `/api/meta`，WebSocket 端口改了不用改页面。

`reader-idle-seconds` 必须大于客户端的 `heartbeat-seconds`，否则在线的枪会被当成空闲连接关掉，然后进入重连。默认是 90 秒和 15 秒。

Windows 自带终端如果把中文日志显示成乱码，把终端代码页改成 UTF-8（`chcp 65001`）再启动，或直接在 IDEA 里运行。字符串本身是 UTF-8。
